# Sentence Stacker

An English grammar arcade game with fourteen levels, an independent tractor timer, five grammar libraries, and a collection of seven Ancient and seven New Wonders.

## Run

Open `index.html` directly, or start a local server:

```bash
npm start
```

Then open <http://localhost:4173>.

## Controls

- `←` / `A`: choose the left sentence
- `→` / `D`: choose the right sentence
- `Esc`: pause
- `G`: open the Grammar Guide
- `M`: mute/unmute

Progress and settings are saved in the browser.
